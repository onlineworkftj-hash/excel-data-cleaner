\# Excel Data Cleaner



A simple Python script that cleans Excel files using pandas.



\### Features:

\- Removes completely empty rows

\- Removes duplicate rows

\- Cleans column names

\- Saves cleaned data to a new Excel file



\### How to use:

1\. Put your dirty Excel file in the same folder

2\. Change the input\_file name in the script

3\. Run: python cleaner.py
